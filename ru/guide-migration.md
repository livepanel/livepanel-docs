# Перенос сайта с другого хостинга

В этом руководстве перенесём сайт на PHP + MySQL с другого хостинга или панели (cPanel, ISPmanager, Plesk и др.) в LivePanel — без остановки сайта.

## 1. Сделайте копию на старом хостинге

1. **Файлы:** скачайте папку сайта (`public_html`, `httpdocs` или похожую) **архивом ZIP или tar.gz**.
2. **База:** в phpMyAdmin **Export → SQL** (или `mysqldump`) — файл `.sql` или `.sql.gz`.
3. Запишите имя базы, пользователя и префикс таблиц из файла настроек сайта (`wp-config.php` в WordPress, `.env` в Laravel).

## 2. Создайте сайт в LivePanel

1. **Сайты → «Создать сайт» → PHP**.
2. Домен — тот же, что у старого сайта. **Версию PHP** выберите как на старом хостинге или ближайшую.
3. Включите карточку **«База данных»**, чтобы создать базу MySQL, или создайте её позже в **«Базы данных»**. Сохраните пароль.

Домен пока указывает на старый сервер — это нормально: посетители видят старый сайт, пока новый не готов.

## 3. Загрузите файлы

![Файловый менеджер](../images/files.png)

1. Откройте плитку **«Файлы»** и зайдите в `www/<домен>`.
2. Удалите стартовый `index.php` / `index.html` панели.
3. Загрузите архив (до 2 ГБ) и **«Распакуйте»** его в эту папку.
4. Если файлы остались в папке внутри архива (например `public_html/`), переместите их на уровень выше.

Для больших сайтов удобнее FTP/SFTP — [FTP, SFTP и SSH](ftp-ssh.md).

## 4. Импортируйте базу

![Импорт](../images/database-import.png)

1. **Базы данных** → меню вашей базы → **«Импорт (.sql)»**.
2. Выберите файл `.sql` или `.sql.gz` (до 2 ГБ).

`DEFINER` с другого сервера очищаются автоматически, представления и триггеры переходят к новому пользователю базы. Подробнее — [Базы данных](databases.md).

## 5. Обновите настройки

Впишите в файл настроек сайта данные новой базы:

| | Значение |
|---|---|
| Хост | `localhost` |
| Имя базы, пользователь, пароль | созданные на шаге 2 |

- **WordPress:** `wp-config.php` → `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `DB_HOST`.
- **Laravel:** `.env` → `DB_*`; затем `php artisan config:clear` в [Терминале](terminal.md).

> В проектах **Laravel и Symfony** посетителям должна быть открыта только папка `public/`. Для этого на шаге 2 создайте сайт через **CMS / Фреймворк → PHP → Фреймворк → Laravel** (или Symfony) — панель сделает корнем сайта папку `public/` проекта. Затем замените установленный пример проекта своими файлами (вместе с `.env` и `storage/`).

## 6. Проверьте до смены DNS

Временно добавьте строку в файл `hosts` вашего компьютера (Windows: `C:\Windows\System32\drivers\etc\hosts`, macOS/Linux: `/etc/hosts`):

```text
IP_НОВОГО_СЕРВЕРА  example.uz www.example.uz
```

Откройте `http://example.uz` в браузере и проверьте, что сайт работает на новом сервере. При ошибках — **Логи → Журнал ошибок**. После проверки удалите строку из `hosts`.

## 7. Переключите DNS на новый сервер

1. Смените A-записи домена (`@` и `www`) на IP нового сервера.
2. Дождитесь распространения (до нескольких часов). Если за это время на старый сайт придут заказы или комментарии, базу, возможно, придётся перенести ещё раз — по возможности на время переноса переведите старый сайт в режим «технических работ».
3. Когда DNS укажет на новый сервер — получите [SSL-сертификат](ssl.md).
4. Включите [автоматическое копирование](backups.md).

## 8. Почта

Почтовые ящики со старого хостинга сами не переносятся. Создайте ящики на новом сервере ([Почта](mail.md)), смените MX-запись, а старые письма перетащите из ящика в ящик по IMAP в почтовой программе.

Не закрывайте старый хостинг неделю-две — отключите его, когда убедитесь, что всё работает.
