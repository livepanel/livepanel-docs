# Команды сервера

На сервере по SSH, от root, работает команда `livepanel`. Список доступных команд:

```bash
livepanel --help
```

| Команда | Назначение |
|---|---|
| `livepanel ip-access on` | Включить доступ к панели по IP — порт 6563 открыт для всех |
| `livepanel ip-access off` | Панель открывается только через свои адреса — порт 6563 закрыт снаружи |
| `livepanel ip-access status` | Показать состояние доступа по IP |
| `livepanel passwd NAME` | Задать новый пароль аккаунту панели |
| `livepanel remove` | Удалить LivePanel и всё, что через него установлено |
| `livepanel --help` | Список команд |

Если ввести неизвестную команду, терминал сообщит об этом и напомнит, что список команд показывает `livepanel --help`.

## Доступ по IP

```bash
livepanel ip-access off
```

Порт 6563 закрывается снаружи, и панель открывается только через свой адрес, например `https://panel.example.uz`. Доступ с самого сервера (`127.0.0.1`) остаётся открытым. Команда работает, только если есть [адрес панели](panel-access.md) с сертификатом Let’s Encrypt или своим — без такого адреса доступ по IP остаётся включённым.

Если адрес панели перестал работать (DNS, срок домена и т. п.), включите доступ по IP снова:

```bash
livepanel ip-access on
```

Та же настройка есть в панели: **Настройки → Адреса панели → Доступ по IP**.

## Пароль панели

```bash
livepanel passwd liveadmin
```

Команда спросит новый пароль. Если оставить его пустым, панель сама создаст пароль и выведет его на экран.

## Удаление панели

```bash
livepanel remove
```

Удаляются сайты и их файлы, базы данных, почта, SSL-сертификаты, резервные копии, веб-, баз данных, FTP- и почтовый серверы, а также программы из раздела **Приложения**. Команда трижды просит подтверждение: `Y` (Yes), одноразовый код с экрана и ещё одно `Y`. Затем каждый этап показывает в своей строке процент выполнения от 0% до 100%.

> Это действие нельзя отменить. Сначала сделайте резервные копии нужных данных — [Резервные копии](backups.md).
