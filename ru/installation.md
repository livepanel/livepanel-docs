# Установка

LivePanel устанавливается на чистый сервер одной командой, обычно за 5–10 минут.

## Требования

| | Минимум | Рекомендуется |
|---|---|---|
| Операционная система | **Ubuntu 22.04 LTS** или **Ubuntu 24.04 LTS**, свежая установка | Ubuntu 24.04 LTS |
| Процессор | 1 vCPU, x86_64 | 2 vCPU и больше |
| Память | 1 ГБ | 2 ГБ и больше |
| Диск | 10 ГБ | 20 ГБ и больше (SSD) |
| Доступ | root или sudo | — |
| Сеть | публичный IP-адрес | — |

Должны быть открыты порты: **80** и **443** (сайты и Let’s Encrypt), **6563** (панель), **22** (SSH). Для почты ещё 25, 465, 587, 993 и 995.

> На сервере не должно быть другой панели (cPanel, Plesk, ISPmanager и т. п.) и существующей конфигурации Nginx/Apache. Чистый сервер — самый надёжный путь к гладкой установке.

## 1. Подключитесь к серверу

Подключитесь с компьютера по SSH (PowerShell или PuTTY в Windows, Терминал в macOS и Linux):

```bash
ssh root@SERVER_IP
```

## 2. Запустите установщик

```bash
curl -fsSL https://livepanel.uz/install.sh | sudo bash
```

Скрипт выполняет шаги и показывает каждый на экране:

1. скачивает пакет LivePanel и **проверяет подпись и контрольную сумму**;
2. устанавливает панель;
3. устанавливает Nginx и системный PHP (FPM): PHP 8.1 на Ubuntu 22.04, PHP 8.3 на Ubuntu 24.04;
4. устанавливает MySQL 8 и phpMyAdmin;
5. устанавливает FTP/SFTP-сервер (ProFTPD);
6. устанавливает клиент Let’s Encrypt (certbot) и Node.js LTS;
7. запускает агент хостинга.

## 3. Сохраните данные для входа

В конце вы увидите:

```text
LivePanel is ready

  Address:   https://SERVER_IP:6563
  Login:     liveadmin
  Password:  ************

  Save this password now: it is shown only once and is not stored.
```

**Сразу сохраните пароль** — он показывается только один раз и не хранится на сервере. Если он потерян, задайте новый на сервере:

```bash
livepanel passwd liveadmin
```

Лог установки — `/var/log/livepanel-install.log`.

## 4. Откройте панель

Откройте в браузере `https://SERVER_IP:6563`. Сначала панель использует собственный (самоподписанный) сертификат, поэтому браузер предупредит, что соединение не защищено — выберите **Дополнительно → Перейти**. Позже панели можно выдать доверенный сертификат или домен: [Адрес панели и SSL](panel-access.md).

Войдите как `liveadmin` с сохранённым паролем — [Первый вход и интерфейс](first-login.md).

## Удаление панели

Чтобы удалить LivePanel и всё, что она установила, выполните на сервере:

```bash
livepanel remove
```

Другие команды сервера — [Команды сервера](console.md).

> Это удаляет и сайты, базы данных и почту. Сначала сделайте резервные копии всего нужного.

## Проблемы

- **«Ubuntu 22.04 or 24.04 LTS is required»** — установлена другая ОС. Переустановите сервер с Ubuntu 22.04 или 24.04.
- **Панель не открывается** — порт 6563 может быть закрыт во внешнем файрволе провайдера. Откройте его в панели провайдера.
- **Установка остановилась** — посмотрите конец `/var/log/livepanel-install.log` и запустите команду снова.
