# Деплой из Git

Подключите к сайту репозиторий GitHub, GitLab или любой другой Git и выкладывайте код на сайт в один клик — или автоматически при каждом `git push`. Откройте плитку **«Git»** на странице сайта.

![Git](../images/git.png)

## Подключение репозитория

1. **Адрес репозитория**:
   - публичный: `https://github.com/user/project.git`;
   - приватный: `git@github.com:user/project.git` (нужен ключ развёртывания, см. ниже).
2. **Ветка** — например `main` или `master`.
3. **Команда после развёртывания** (необязательно) — выполняется в папке сайта после загрузки файлов:

   | Тип сайта | Пример |
   |---|---|
   | PHP | `composer install --no-dev --optimize-autoloader` |
   | Node.js | `npm install && npm run build --if-present` |
   | Python | `.venv/bin/pip install -r requirements.txt` |

4. Нажмите **«Подключить и загрузить»**. У публичного репозитория файлы загружаются сразу.

## Приватный репозиторий: ключ развёртывания

Панель создаёт для сайта отдельный **ключ развёртывания** (SSH-ключ) и показывает его на странице. Добавьте его в репозиторий:

- **GitHub:** репозиторий → **Settings → Deploy keys → Add deploy key** → вставьте ключ (права на запись не нужны).
- **GitLab:** **Settings → Repository → Deploy keys**.

Затем нажмите **«Развернуть»**.

## Как проходит развёртывание

1. Выбранная ветка забирается из репозитория и записывается в папку сайта (`git fetch` + `git checkout -f`).
2. Если есть подмодули, они тоже обновляются.
3. Стартовая страница панели удаляется, если её нет в репозитории.
4. Выполняется команда после развёртывания.
5. На сайтах Node.js и Python служба перезапускается.

**Файлы, которых нет в репозитории, остаются** — загруженные картинки, `.env`, кэши сохраняются. Всё выполняется от имени пользователя сайта.

В команде работают `node`, `npm`, `npx`, `composer`, `php` и Python-окружение сайта.

> Не пишите в команду развёртывания бесконечные команды вроде `npm start` — через 20 минут развёртывание остановится с ошибкой. Постоянную работу приложения обеспечивает служба сайта ([Сайты на Python и Node.js](python-nodejs.md)).

## Вебхук: развёртывание при каждом push

Добавьте **адрес вебхука** со страницы в репозиторий:

- **GitHub:** **Settings → Webhooks → Add webhook** — Payload URL: адрес вебхука, Content type: `application/json`, событие: **Just the push event**.
- Если сертификат панели самоподписанный, отключите **SSL verification** (или выдайте панели доверенный сертификат — [Адрес панели и SSL](panel-access.md)).

Адрес содержит секретный токен — не передавайте его другим. Кнопка обновления создаёт новый адрес (старый перестаёт работать).

## Результаты развёртывания

Внизу страницы — последнее развёртывание: состояние, время, кто запустил (**из панели** или **через вебхук**), коммит и полный лог. При ошибке в логе указано, какой шаг не удался:

| Ошибка | Причина |
|---|---|
| Не удалось забрать репозиторий | Неверный адрес или ветка, либо ключ развёртывания не добавлен в приватный репозиторий |
| Команда после развёртывания завершилась с ошибкой | Ошибка в команде — смотрите конец лога |

**«Отключить»** убирает настройки Git; файлы сайта и папка `.git` остаются.
