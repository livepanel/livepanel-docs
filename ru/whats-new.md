# Что нового

LivePanel обновляется автоматически (проверка каждые 6 часов и при входе администратора). Номер версии — дата и время (UTC): `YYYY.MM.DD.HHMM`. Текущая версия видна внизу меню панели. Здесь последние изменения — новые сверху.

## 2026.11.26.1605 — Статистика сайта

- **Отчёт о посещениях** (GoAccess) снова открывается: раньше страница бесконечно показывала загрузку. Отчёт по-прежнему открывается изолированно от панели (sandbox) — [Статистика](statistics.md).

## 2026.11.26.1523 — Wildcard SSL и DNSSEC

- **Wildcard SSL (Premium)** — один сертификат Let’s Encrypt для домена и всех поддоменов (`example.uz` + `*.example.uz`). Панель сама добавляет и удаляет проверочную TXT-запись в DNS-зоне, сертификат продлевается автоматически — [SSL-сертификаты](ssl.md#wildcard-sertifikat-premium).
- **DNSSEC** — зона подписывается, панель показывает DS-запись для регистратора — [Домены и DNS](dns.md#dnssec).
- API v2: `wildcard` в `POST /sites/ssl`, действие `dnssec` в `POST /dns` — [API v2](api-reference.md).

## 2026.11.26.0718 — Защита лицензии

- Ключ Free не может заменить активную лицензию Premium (`409 license_not_better`); для одного тарифа остаётся более долгий.
- Убрана неработавшая «активация по коду»: платные ключи приходят сами после оплаты — [Лицензия и тарифы](license.md#kak-zasiseny-kluci-licenzii).
- livepanel.uz отдаёт ключ только серверу — владельцу лицензии.

## 2026.11.25 — API v2

- **API v2 (Premium)**: почти все возможности панели через API — сайты, файлы, базы, DNS, почта, FTP, cron, резервные копии, Git, аккаунты, лимиты, брендинг и сервер. 13 разделов, для каждого права «чтение» и «запись» — [API-токены](api-tokens.md), [Справочник API v2](api-reference.md).
- Примеры на PHP, Node.js и Bash, файл OpenAPI: [openapi.json](https://wiki.livepanel.uz/openapi.json). Чтобы отдать документацию ИИ, на каждой странице есть кнопка «Копировать для ИИ» и ссылка `.md`.
- Файловый менеджер: создание существующей папки отвечает `file_exists`; при загрузке `overwrite=1` заменяет файл.
- Подключение резервного хранилища (Google Drive, Dropbox) возвращается только на собственный адрес панели.
