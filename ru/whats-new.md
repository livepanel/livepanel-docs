# Что нового

LivePanel проверяет новую версию каждые 6 часов и при входе администратора; она ставится автоматически или по кнопке **Обновить** — [Обновления и уведомления](updates-notifications.md). Номер версии — дата и время (UTC): `YYYY.MM.DD.HHMM`. Текущая версия видна внизу меню панели. Здесь последние изменения — новые сверху.

## 2026.11.28.1714 — Расписание обновлений и проверка на вирусы

- **Автообновление** теперь работает по расписанию: раз в 1–7 дней, в выбранное время (AM/PM) — [Обновления и уведомления](updates-notifications.md).
- В сообщении «Доступно обновление» вверху есть кнопка **Что нового**: перед установкой видно, что изменилось в версии.
- **Настройки → Проверка на вирусы**: все сайты проверяются ClamAV по расписанию; если найдены подозрительные файлы, администратору приходит письмо — [Настройки панели](panel-settings.md).
- Письма теперь пишутся на всех языках панели (также испанский, украинский, турецкий, итальянский).

## 2026.11.28.1654 — Новые языки

- Панель теперь доступна на **испанском, украинском, турецком и итальянском** (язык выбирается в меню). Письма на этих языках приходят на английском.
- При открытии списка языков флаги больше не переворачиваются.

## 2026.11.28.1617 — Вход по HTTP

- Если открыть `http://IP:6563`, панель сама перенаправляет на `https://`.

## 2026.11.28.1534 — Настройка автообновления

- **Настройки → Автообновление**: автоматический приём обновлений можно включить или выключить. По умолчанию выключен.
- Если выключен, при выходе новой версии в правом верхнем углу экрана появляется сообщение `{версия} Доступно обновление` и кнопка **Обновить**; панель обновляется по кнопке — [Обновления и уведомления](updates-notifications.md).

## 2026.11.26.1641 — Веб-файрвол (WAF) и wildcard SSL с внешним DNS

- **Веб-файрвол (WAF)** — ModSecurity + OWASP CRS для каждого сайта: режим блокировки или только наблюдения, исключения для WordPress/Drupal/Nextcloud, список остановленных запросов и отключение ложного правила в один клик — [Безопасность сайта](site-security.md#veb-fajrvol-waf).
- **Wildcard SSL работает и с DNS у другого провайдера**: достаточно одной NS-записи `_acme-challenge` у регистратора, панель показывает точную запись — [SSL-сертификаты](ssl.md#wildcard-sertifikat-premium).
- API v2: `GET /sites/waf`, поля `waf`, `waf_app`, `waf_skip` в настройках сайта.

## 2026.11.26.1605 — Статистика сайта

- **Отчёт о посещениях** (GoAccess) снова открывается: раньше страница бесконечно показывала загрузку. Отчёт по-прежнему открывается изолированно от панели (sandbox) — [Статистика](statistics.md).

## 2026.11.26.1523 — Wildcard SSL и DNSSEC

- **Wildcard SSL (Premium)** — один сертификат Let’s Encrypt для домена и всех поддоменов (`example.uz` + `*.example.uz`). Панель сама добавляет и удаляет проверочную TXT-запись в DNS-зоне, сертификат продлевается автоматически — [SSL-сертификаты](ssl.md#wildcard-sertifikat-premium).
- **DNSSEC** — зона подписывается, панель показывает DS-запись для регистратора — [Домены и DNS](dns.md#dnssec).
- API v2: `wildcard` в `POST /sites/ssl`, действие `dnssec` в `POST /dns` — [API v2](api-reference.md).

## 2026.11.26.0718 — Защита лицензии

- Ключ Free не может заменить активную лицензию Premium (`409 license_not_better`); для одного тарифа остаётся более долгий.
- Убрана неработавшая «активация по коду»: платные ключи приходят сами после оплаты — [Лицензия и тарифы](license.md#kak-zasiseny-kluci-licenzii).
- livepanel.uz отдаёт ключ только серверу — владельцу лицензии.

## 2026.11.25 — API v2

- **API v2 (Premium)**: почти все возможности панели через API — сайты, файлы, базы, DNS, почта, FTP, cron, резервные копии, Git, аккаунты, лимиты, брендинг и сервер. 13 разделов, для каждого права «чтение» и «запись» — [API-токены](api-tokens.md), [Справочник API v2](api-reference.md).
- Примеры на PHP, Node.js и Bash, файл OpenAPI: [openapi.json](https://wiki.livepanel.uz/openapi.json). Чтобы отдать документацию ИИ, на каждой странице есть кнопка «Копировать для ИИ» и ссылка `.md`.
- Файловый менеджер: создание существующей папки отвечает `file_exists`; при загрузке `overwrite=1` заменяет файл.
- Подключение резервного хранилища (Google Drive, Dropbox) возвращается только на собственный адрес панели.
