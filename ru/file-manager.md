# Файловый менеджер

Файловый менеджер позволяет работать с файлами сайта в браузере: загружать, редактировать, архивировать и многое другое. Откройте его плиткой **«Файлы»** на странице сайта. У аккаунта должно быть право **«Управление файлами»**.

![Файловый менеджер](../images/files.png)

Он показывает домашнюю папку пользователя сайта и никогда не выходит за её пределы. Файлы сайта — в `www/<домен>`. Все действия выполняются от имени пользователя сайта, поэтому владельцы файлов остаются правильными, а дисковая квота учитывается.

## Загрузка

- Кнопка **«Загрузить файл»** или **перетаскивание** файлов в окно.
- Один файл — до 2 ГБ. Можно загружать несколько файлов сразу.
- При нескольких файлах показывается **одна полоса прогресса по их общему объёму**, например «Загрузка 20 файлов — готово 7 · 45%». Файлы, которые не загрузились, перечисляются с причиной.
- Папки загружать нельзя — загрузите архив и распакуйте его в панели.

## Новый файл и папка

**«Создать»** создаёт пустой файл или папку.

## Действия

Двойной щелчок по файлу открывает или редактирует его. Через меню строки или выделив несколько элементов:

| Действие | Примечание |
|---|---|
| Открыть / Редактировать | Текстовые файлы до 2 МБ, с подсветкой синтаксиса; можно выбрать кодировку |
| Скачать | Сохранить на компьютер |
| Переименовать | |
| Переместить, Копировать | В другую папку |
| Изменить права | Например `644` (файл), `755` (папка); рекурсивно — «Также для содержимого» |
| Добавить в архив | Архив `.zip` или `.tar.gz` |
| Распаковать | ZIP, TAR, GZ, RAR, 7Z и другие |
| Удалить | Папки удаляются вместе с содержимым |

Если выделено несколько элементов, перемещение, копирование, права, архив и удаление применяются ко всем.

## Об удалении

- Удалить можно любой файл или папку; папки только для чтения тоже удаляются вместе с содержимым.
- Если удалить собственную папку сайта или `www`, панель **создаст её заново, пустой** — сайт продолжит работать.
- Эти папки нельзя переместить или переименовать, потому что сайт работает по этому пути.

## Статистика диска

**«Статистика диска»** показывает, что занимает место в папке: самые большие папки, самые большие файлы и объём по расширениям. Полезно, когда диск заполняется.

## Безопасность

Символические ссылки не могут вести за пределы папки пользователя сайта — другие сайты и системные файлы остаются невидимыми.
